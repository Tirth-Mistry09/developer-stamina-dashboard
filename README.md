# Developer Stamina Dashboard

## Project Description

The Developer Stamina Dashboard is a React-based application developed using Vite. The project simulates a developer’s coding stamina while also displaying technical skills and dynamic greetings based on the current time. This project focuses on React fundamentals such as components, props, state management, conditional rendering, and event handling.

---

## Virtual DOM Explanation

React uses a Virtual DOM to efficiently update the user interface whenever the stamina value changes. Instead of reloading the entire webpage, React updates only the modified elements, which improves performance and provides a smoother user experience.
